Support

Before reporting a problem, update to the latest release and reload the Steam or browser page. Include the extension version, browser or Steam client, Steam game URL, expected result, and a screenshot when possible.

Bug reports and feature requests

Open a public GitHub issue. Do not include passwords, authentication tokens, private browsing data, or other sensitive information.

Security reports

Potential security vulnerabilities should not be filed publicly. Follow the private reporting instructions in the repository's Security Policy.

HowLongToBeat or Steam data

The extension is an independent interface. Corrections to HowLongToBeat or Steam's own content should be reported to the respective service.
